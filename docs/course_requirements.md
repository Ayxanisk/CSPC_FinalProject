# Course Handout Requirements

This file summarizes requirements stated in the supplied capstone handout. They
are constraints for the team's submission; they are separate from the user's
request to select a STEAD topic and research questions.

## Paper

- English, using the LaTeX template provided on Moodle.
- Maximum 5–6 pages, excluding references.
- Include the problem and research question, dataset description, short related
  work, methods, results with figures/tables, and conclusions.
- Include an AI-use disclosure and a contribution table.

## Public repository

- Reproducible environment file with pinned dependencies.
- A Snakemake pipeline that runs from raw data to all paper results and figures.
- pytest tests and a README with setup and reproduction instructions.
- Include `LICENSE` and all required code/data or reproducible data acquisition.
- The implementation must be the team's own work.

## Final upload

Submit one ZIP containing the full Overleaf/LaTeX project, the compiled paper
PDF, and a `.txt` file with the public GitHub repository link. The handout gives
the submission deadline as 4 December 2026, 23:59 Baku time.

Team registration, dataset approval, and submission instructions should be
checked against Moodle. This summary does not replace the handout or Moodle
template.
